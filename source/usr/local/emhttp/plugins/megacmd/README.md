**MEGAcmd**

MEGAcmd brings [MEGA](https://mega.nz) cloud storage sync to Unraid. It uses the official command-line client from MEGA.

Log in to your MEGA account from Settings > MEGAcmd. Set up two-way syncs, or one-way backups, between MEGA folders and any Unraid share. No terminal is needed: you manage sync setup, transfer history, notifications, a crash watchdog, speed limits, and MEGAcmd version updates all from the webGUI.
